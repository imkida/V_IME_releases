# Vime for macOS 1.8.0

这次更新让设置更清楚，也让听写状态和结果写回更好理解。

## 优化

- **设置更清楚**：默认服务、官方模板和个人配置分开显示，方便检查当前使用的服务。
- **听写状态更直观**：状态条支持浅深色与拖动，选区替换或编辑后的撤销入口更清楚。
- **菜单栏更好用**：风格选中和快捷键提示更清楚，历史与设置更容易找到。

## 修复

- **保留本机设置**：修复本地统计开关相关问题，保留已有密钥、配置与听写历史。
- **写回更稳妥**：改善打开面板后向原输入框写入结果的处理；取消或切换输入目标时不抢回焦点。

- 纠错学习提示仍在调查，本次更新未修复。
