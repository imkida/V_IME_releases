# Vime for macOS 1.8.1

2026-10-02 · macOS 14 及以上 · build 2026100203

菜单和听写预览更清晰，浅色与深色外观下的显示更一致。

## 优化

- **菜单更易读**：增强文字、按钮和所选输出风格的对比度。
- **预览更清楚**：实时听写内容改用独立小窗显示。
- **外观更统一**：预览窗口与听写状态条保持一致。

## 修复

- **修复颜色更新**：切换浅色或深色外观时，预览文字颜色会及时更新。

支持 macOS 14 及以上，可直接覆盖安装。已有配置、服务密钥与听写历史保留；识别模型、智能整理默认策略、输入保护与撤销行为不变。
